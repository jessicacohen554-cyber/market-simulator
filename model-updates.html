Model Updates

The model’s change record is kept where the changes land — in the repository’s dated changelog, the per-ISO calibration logs, and the dashboards that score every run. This page points at each of them.

This page used to carry a hand-written impact log. It stopped in June 2026, and its entries compared probe runs that the dashboard no longer retains — only each ISO’s designated keeper run is kept; everything superseded lives in git history. Rather than let it drift, it now points at the records that are maintained with every change.

Measured impact is never narrated separately from the run that produced it: a run’s scorecard, diagnostics and determination are on the dashboards, and the reasoning behind each promotion is in that ISO’s calibration log.

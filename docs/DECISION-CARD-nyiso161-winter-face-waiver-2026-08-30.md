## 3. WHAT A WAIVER WOULD AND WOULD NOT CHANGE — stated before the options

* **It relabels the backcast; it does not change the model.** Under every
  option the forecast lane still under-prices downstate NYISO winters by the
  face's magnitude (~$4/MWh of the 2025 annual mean, concentrated in
  Jan/Feb, downstate zones). A waiver moves the label, not the number; the
  miss stays reported at full magnitude on the determination basis either
  way (that much is non-negotiable house style, as with C3c).
* **The recorded marker re-entry route requires CALIBRATED, not CWC.** Q5-W:
  "Re-entry is a NEW explicit owner declaration once the keeper again scores
  CALIBRATED." Option B (CWC) therefore does NOT by itself re-open the
  `complete` marker or the validation tier — reaching those through Option B
  would need a second, separate owner relaxation of the re-entry bar, which
  this card does not recommend bundling.
* **What CALIBRATED (Option C) would unlock downstream:** marker re-entry
  eligibility → the 2022→2020 validation touchpoints → the touchpoint loop.
  Honest cost of taking that road on a waived keeper: the touchpoints teach
  by surprising us (neiso-85/86 is the model case), and a 2020–2022 winter
  face failing for the already-known walled reason spends part of each
  year's power to surprise on a diagnosis we already own.
* **Precedent surface.** C3c's non-downgrading treatment survived three
  amendments precisely because its guards are narrow (lone-failure only,
  supporting tier only, one ledgerable criterion). Every widening was
  measured across all registered runs before landing. Any option below that
  amends the rubric inherits that discipline: scorer-only change, effect
  snapshot across all registered runs, D-5(b) re-verification per keeper,
  version bump with the owner's verbatim ruling recorded.

## 4. THE GUARD ANALYSIS — why this is harder than C3c, exactly

1. **Epistemic class.** C3c is a *measured model-class limitation*: an
   hourly LP with $0 reserve offers cannot form the RT scarcity tail, shown
   across ISOs, ledgered with the miss quantified every run. The winter face
   is an *unbuilt mechanism*: the driver is real (nyiso-153 proved the
   downstate under-commitment is real and improvable), the model is
   known-incomplete there, and what blocks completion is data access. A
   waiver therefore asserts "the input is unobtainable," not "the model
   class cannot do this." Those are different claims and must not share a
   label — Option B below gives the access class its own name and budget
   line rather than stretching "model-class."
2. **Tier.** C3a is load-bearing. The v3.0 guard restricts model-class
   classification to supporting-tier criteria, and the nyiso-156 card called
   that guard "one of the rubric's core protections" when it declined to
   breach it for the summer face. Any option that caveats C3a-2025 relaxes
   that protection for the access class — knowingly, in the open, or not at
   all.
3. **Budgets.** The standing budgets read >1 ledgered or >0 protective
   caveats ⇒ NOT-YET, and C3c already spends the single ledgerable slot. An
   access-blocked caveat must therefore be a NEW budget line (max one, never
   a protective criterion), or Option B is arithmetically unreachable.
4. **Mechanics.** The C3c rule works by reclassifying the lone failure
   before determination; the same shape works here and the order matters:
   the access rule runs first (C3a-2025 FAIL → ACCESS-BLOCKED CAVEAT on its
   eligibility tests), C3c then becomes the lone failure and its own
   standing rule fires. Result under B: two caveats in separate budgets,
   determination **CALIBRATED-WITH-CAVEATS**; under C the access caveat is
   declared non-downgrading and the same pipeline reads **CALIBRATED**.
5. **Eligibility tests an access-blocked caveat must pass (all fail-closed),
   written so the class can never become an escape hatch:**
   * (a) **decisive attribution** — a committed same-keeper attribution
     probe (no solve) shows the named blocked component alone, removed
     arithmetically, returns the record to band (here: −7.62 + 3.92 →
     in band). A component that merely helps does not qualify;
   * (b) **access-class block with a filed stop-with-cause record** — a
     named walled source, a session-executable route proven absent
     (nyiso-158 §1.4's measured exhaustion + nyiso-160's access stop), and
     the re-open bar filed. "We have not looked" never qualifies;
   * (c) **lone non-C3c failure** — every other criterion passes or is the
     ledgered C3c; any second failure silences the rule and everything
     stands, exactly as C3c's guard (a) works;
   * (d) **auto-lapse** — the caveat names its re-open conditions (the
     nyiso-97 §5 set) and lapses the moment any is met or the keeper
     changes; a new keeper must re-attest (a)–(c) on its own committed
     record before the caveat re-attaches;
   * (e) **never protective, never silent** — C6/C8 are never eligible; the
     caveat is named on the determination basis at full magnitude every
     time it is applied.

## 5. OPTIONS

| # | option | what it costs | what it buys |
|---|---|---|---|
| **A** | **No amendment — NOT-YET stands** *(RECOMMENDED)* | nothing now; the determination stays NOT-YET while the wall stands (possibly indefinitely) | the fully honest state: NOT-YET currently means exactly "one identified input missing, everything else clean" — which is true, precise, and already narrower than any prior NYISO fail set; the access retry (§2) and the standing watch keep the structural route alive at zero governance cost |
| **B** | **Amend: create the ACCESS-BLOCKED INPUT caveat class** (v3.4; §4.5 tests (a)–(e); own budget line, max one, downgrading) → keeper reads **CALIBRATED-WITH-CAVEATS** | a real, deliberate relaxation of the v3.0 tier guard for one narrowly-tested class; scorer change + effect snapshot across all registered runs + D-5(b) re-verification; CWC starts meaning "calibrated where the inputs exist, one named wall priced in" | the label stops under-selling the lane (the miss is a data wall, not open work); auto-lapse keeps the incentive to close the face honest; does NOT touch the marker re-entry bar (stays CALIBRATED-gated) |
| **C** | **Amend further: the access caveat reads non-downgrading** → keeper reads **CALIBRATED** | everything B costs, plus: breaches the "only C3c is non-downgrading" line that three amendments defended; makes CALIBRATED reachable while a load-bearing criterion fails for a reason that is contingent (a login) rather than structural; invites the same claim from every ISO's next walled input; touchpoint years then spend surprise-power on a known diagnosis | marker re-entry eligibility without new data; the program's best-ISO optics |

**Why A over B, and B over C.** A costs nothing and stays exactly truthful;
its only cost is optics, and the §2 access fact means the wall itself may
yet fall for the price of a registration request. B is the honest shape IF
the owner wants the label to move now: it prices the wall openly, tests
eligibility fail-closed, lapses automatically, and refuses the marker
shortcut — but it still relaxes a core guard for a benefit that is mostly
label. C reaches the owner's presumable goal (CALIBRATED) by making the
determination conditional on data availability, which is the exact currency
the determination exists to protect; nyiso-156 §5C declined a weaker version
of the same trade and nothing in the new terrain strengthens the case — the
wall got harder, not the model better. If C is ever taken, it should be
taken as an explicit owner override recorded verbatim, not as a recommended
route.

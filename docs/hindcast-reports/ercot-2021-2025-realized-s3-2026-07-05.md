## Root cause (corrected): the hindcast LP is structurally long, so the ORDC overlay is inert

The overlay branch (`runner.py:1561`) fires — its three conditions
(`scarcity_pricing_enabled`, `scarcity_price_overlay`, `not energy_reserve_coopt`)
are all met and confirmed in the run config. It adds ≈ $0 because **the
perfect-foresight LP on the ample 2020-vintage fleet, against realized (un-grown)
2021-2025 demand, never goes scarce.** Persisted energy-price duals, per scored
year (max over all 8760 h × 7 zones):

| year | mean $/MWh | max $/MWh | hours (any zone) > $100 | > $500 |
|---|--:|--:|--:|--:|
| 2021 | 21.8 | 41.8 | 0 | 0 |
| 2023 | 16.1 | 26.2 | 0 | 0 |
| 2024 | 14.1 | 29.0 | 0 | 0 |
| 2025 | 24.0 | 45.9 | 0 | 0 |

There is **not a single scarcity-priced hour** in any scored year. The ORDC adder
keys off reserve headroom; a system whose marginal unit is a cheap gas/coal unit
in every one of 8760 hours has ample reserves → LOLP ≈ 0 → adder ≈ 0. So
`econ_prices = result.prices + adder` ≈ `result.prices`, and the retirement
screen's pro-forma inframarginal margin against a $14–24-mean / <$46-max curve
leaves the entire coal fleet far below its ~52 $/kW-yr FOM bar — exactly as it
did with scarcity off.

This **corrects the Stage-2 report's root-cause reading**. Stage 2 attributed
the scarcity-free signal to the disabled toggle (`scarcity_pricing_enabled=False`)
and recorded "adopt the ORDC footing" as the fix. Stage 3 shows the scarcity-free
signal is **not a consequence of the toggle** — it is an artifact of the
hindcast's perfect-foresight LP on an over-supplied vintage fleet, which produces
no scarcity for the overlay to price *regardless* of the toggle. Turning the
footing on is still the correct harness posture (the hindcast should see the same
price formation the forecast uses — rule 1), but it is a **no-op in this regime**.
The over-retirement's true drivers are unchanged and are:

1. **The accredited floor releases a genuinely scarcity-free revenue signal.**
   The floor now correctly counts the realized-era wind/solar/storage pools, so
   it no longer un-retires everything; what it releases, the (inert-here) revenue
   stack cannot rescue. Solar entry fails on the same $14–24 flat curve (shape-
   aware capture of a scarcity-free price cannot clear solar's annualized fixed
   cost, ITC included). *This is a property of the perfect-foresight hindcast LP,
   not of the forward market* — the forecast path (grown demand, tighter fleet)
   does produce scarcity hours the overlay prices, which is why the footing
   matters there and not here.
2. **Retirement grain is lumpy after re-aggregation** (report-only, no fix — see
   below).

### Zone-bin re-aggregation grain (report-only, rules 1/11/14 — carried from s2)

evolution step the fleet re-collapses into **zone-level bins**, so a single

a parallel session). Logged as the standing grain limitation for the next

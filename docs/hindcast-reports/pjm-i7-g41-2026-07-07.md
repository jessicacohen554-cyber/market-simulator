# PJM hindcast invariant I7 — G-41 implementation (market-design-dependent floor)

_2026-07-07 · W2C forecast lane · implements `docs/handoffs/pjm-hindcast-i7-decision-2026-07-06.md` · owner-approved **market-design-dependent** variant · forecast-side only (no backcast keeper, no holdout touched)_

## Decision implemented

Owner selected the memo's recommendation: **I7's definition is market-design-dependent**, mirroring the mechanism that actually clears capacity in each ISO (rule 1 — the definition follows the real market, never what greens the line):

- **Capacity-market ISOs** (`MARKET_DESIGN[iso].capacity_market`: PJM/MISO/NYISO/NEISO/CAISO) — an **absolute** adequacy floor, with the reserve-margin adequacy **backstop default-on** (the LP analogue of PJM RPM's absolute-IRM procurement).
- **Energy-only ERCOT** — a **retirement-bounded** floor (evolution must not over-retire below the floor; a fleet that started below it is tolerated), **backstop off** (no absolute floor in an energy-only market — an under-remunerated unit exits and ORDC prices the scarcity).

Both preconditions from the memo were satisfied before enabling the backstop:

1. **Checker floor reconciled with the model's adequacy requirement.** `check_i7_reliability_floor` no longer measures the crude nameplate-thermal / hydro-only / hardcoded-0.15 proxy. For capacity-market ISOs it now compares the **model's own accredited firm capacity** — persisted per solved year as `reserve_margin` (= `accredited_firm_mw / peak − 1`, from `accredited_firm_capacity_mw`: thermal at UCAP, wind/solar/storage at ELCC) — against the **model's own requirement** `resolve_adequacy_requirement_mw` (firm peak × (1 + per-ISO PRM) × ICAP→UCAP ratio). Checker and model now measure the same quantity, so the backstop satisfies I7 honestly rather than by coincidence.
2. **Backstop default gated by market design, not a blanket flip.** `ScenarioConfig.reserve_margin_build_enabled` is now tri-state (`None` default → resolve per `MARKET_DESIGN[iso].capacity_market`; explicit `True`/`False` overrides, rule 21). Energy-only ERCOT and ISOs absent from `MARKET_DESIGN` resolve **off** → byte-identical to the pre-G-41 default.

## I7 state, before → after

The reconciliation alone (precondition 1) already flips PJM's I7 from FAIL to PASS on the **existing** (backstop-off) `pjm-2021-2025-realized` bundle: the model's accredited firm capacity clears its own UCAP/ELCC + IRM requirement every solved year by a wide margin. The original ~1–4 k MW FAIL was a **checker-convention artifact** — the old proxy measured nameplate thermal against a hydro-only/0.15 floor, a different and stricter quantity than how PJM accredits capacity.

Existing (repaired-demand, backstop-off) bundle, reconciled I7:

Zero backstop MW built in any year — PJM's accredited firm capacity (thermal UCAP + wind/solar/storage ELCC) clears the requirement by 40–47 GW throughout 2023–2025, so the now-default-on backstop is structurally present but does not fire. This is the expected outcome: the backstop is the RPM analogue (rule 1) and guards forecasts that *do* fall short, but the 2020-vintage fleet is already well above PJM's IRM.

> **2021 seed-year note:** the 2021 `peak_demand_mw` reads 2.1 × 10⁹ in this bundle because the EIA-930 `PJM hourly` extract (`data/raw/eia-930-hourly/PJM hourly.parquet`) carries a corrupted Demand value for 2021 (≈ INT32_MAX). The new `_load_pjm_hourly_demand` path (commit 59b955c) picks this up; the old bundle's demand-profiles fallback had the correct 149,590 MW. Year 2021 is the seed (not scored, no capacity evolution), so the corruption does not propagate — 2023–2025 peaks, fleets, and I7 margins are unaffected. The formal invariant checker (`check_forecast_invariants.py`) reports I7 FAIL on 2021 only; the scored years pass clean.

**ERCOT control (energy-only → backstop off, unchanged):** `resolve_reserve_margin_build_enabled(config, "ERCOT")` returns `False` for `reserve_margin_build_enabled=None` (default) because `MARKET_DESIGN["ERCOT"].capacity_market=False`. The existing ERCOT realized bundle (`ercot-2021-2025-realized`) has zero backstop builds across all solved years (2021/2023/2024/2025), byte-identical to the pre-G-41 default.

## 2. Reconstruction recipe (re-apply on a session with working transport)

The mechanism is default-off; re-applying it is optional (it is NOT a keeper).
All four source edits are additive and present in local commit `a86777a`.

### 2a. `scripts/data/derive_ercot_offer_midcurve.py` (NEW — pushed with this doc)
Frozen derive. Within-unit HSL-share sampling of the 60-Day DAM disclosure
(`60_DAY_DAM_DISCLOSURE_60d_DAM_Gen_Resource_Data_<year>_*.parquet`,
`QSE submitted Curve-MW/Price 1..10`), Resource-Type→class map
(CCGT90/CCLE90→CC, SCGT90/SCLE90→CT_PEAKER, GSREH/GSNONR/GSSUP→ST_GAS),
committed rows only (`Resource Status` ~ ON, HSL>0). Implied-HR mult =
offer_price / (Henry-Hub daily + ERCOT basis −0.5). Capacity(HSL)-weighted MEAN
per (class, year, net-load bin, share); net-load bin = within-year percentile of
per-(date,HE) summed awarded quantity; edges 0.50/0.70/0.85/0.95; shares
0.1..0.9 + top belt 0.975/0.995. Writes
`data/raw/_validation-source/ercot_offer_midcurve_condbinned.json` (+ summary
CSV). Run: `python scripts/data/derive_ercot_offer_midcurve.py --years 2023 2024 2025`.

### 2b. `src/market_sim/config/scenarios.py` (ScenarioConfig, +2 fields)
```python
ercot_offer_surface_midcurve_conditional: bool = False
ercot_offer_surface_midcurve_path: str | None = None
```

### 2c. `src/market_sim/data/fleet.py` (NEW builder — mirrors `build_pjm_offer_midcurve_conditional_markup`)
`_ERCOT_MIDCURVE_CLASS_OF = {"CC_REGULAR":"CC","CC_CHP":"CC","CT_PEAKER":"CT_PEAKER"}`
(ST_GAS excluded — drag owns it, rule 19). `build_ercot_offer_midcurve_conditional_markup(fleet_arrays, generators, mc_base, net_load_mw, config, year)`:
gate on the flag + iso=="ERCOT"; load the frozen JSON (default path
`CALIBRATION_DIR/ercot_offer_midcurve_condbinned.json`); per-hour net-load bin
via `np.searchsorted(np.quantile(net_load, edges), net_load)`; delivered-gas day
series (HH + ERCOT basis); for each plant order tranches by mean base cost,
compute within-plant share midpoints; for `econ*`-suffix rows interp the
measured mult at the row's share, `target = mult*gas_day`,
`markup = max(0, min(target, 0.95*VOLL) - mc_base[g])`. P1-only. Logs "no econ
row floored ... byte-identical" when inert.

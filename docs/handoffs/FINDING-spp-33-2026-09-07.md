## 4. The `marginal_heat_rate` divisor mismatch — inert for the keeper, live for the forecast

SPP-20's block comments construct each `marginal_heat_rate` as **`mean_LMP / Henry Hub`**:
`27.90 / 2.54 = 10.98`, `23.47 / 2.54 = 9.24`, `48.36 / 2.54 = 19.04`, pooled to 11.24 / 9.19 /
13.51. But the seam prices as **`(henry_hub + gas_basis) × HR × shape`**
(`neighbor_price.neighbor_gas_price`), so the HR that reproduces a measured mean must divide by
**`HH + basis`**. The registered values consequently mis-construct their own anchor's annual mean:

| Seam | basis $/MMBtu | registered flat HR | basis-consistent pooled HR | constructed mean vs measured, 2023 / 2024 / 2025 |
|---|---:|---:|---:|---:|
| MISO | **+0.30** | 11.24 | **10.09** | **+14.4 % / +6.5 % / +13.5 %** (over-prices) |
| AECI | **−0.26** | 9.19 | **10.23** | **−10.7 % / −23.9 % / +10.5 %** |
| ERCOT | **−0.50** | 13.51 | **16.78** | **−43.0 % / −14.9 % / +25.6 %** |

**Why this does not touch the first keeper.** `neighbor_price` precedence is
`hr_by_year` → gas-elastic → flat `marginal_heat_rate`. With §3's table armed, every backcast year
2023–2025 resolves at step 1 and the flat value is **unreachable**. It is the **forecast/hindcast**
fallback — where a +14 % MISO seam over-price would open a fake import spread of exactly the kind
the `derive_neighbor_hr_by_year.py` docstring names as the PJM 2025 over-export root cause.

**Not fixed here.** `spec.py` is SPP-51's file (this lane's explicit not-touch list). Routed as
§6 R2, with the correction values above.

## 5. Gas elasticity — derived, and only one of three seams is armable

Formula, `derive_neighbor_hr_elasticity.py::derive`, unchanged: OLS of `mean_anchor_LMP / K` on
`neighbor_gas_price`, three points per seam.

| Seam | `hr_phys` | `hr_adder` | R² | slope sign | mean \|err\| flat → elastic |
|---|---:|---:|---:|:--:|---|
| **MISO** | 9.00 | 3.22 | 0.984 | ✅ | 1.15 → **0.21** |
| **AECI** | 3.04 | 17.06 | 0.953 | ✅ | 1.62 → **0.16** |
| **ERCOT** | **−0.17** | 36.27 | **0.0001** | ❌ | 5.10 → **5.53** (*worse*) |

**MISO reads gas-set** (large slope, small adder) and **AECI wind-set** (small slope, large adder)
— the same two signatures `_HR_GAS_ELASTIC`'s own comment names for MISO's PJM and SPP seams, from
SPP's data, independently.

**ERCOT's fit is degenerate and must not be armed.** R² = 0.0001, a **negative** `hr_phys` (an
LMP that *falls* as gas rises — physically wrong), and the elastic form is **worse than the flat
fallback in every year**. Three points, one of which is 2023's scarcity summer, cannot identify an
affine gas response; the honest statement is that this seam has **no identified elasticity** and
should stay on its flat structural value forward. The columns `fit_r2` and `hr_phys_sign_ok` are
in `spp_seam_hr_elasticity.csv` so this cannot be read past.

### The architectural blocker SPP-51 will hit

`_HR_GAS_ELASTIC` (`src/market_sim/data/neighbor_price.py:120`) is keyed by neighbour **name,
globally**, and guarded by an import-time uniqueness assert
(`_assert_hr_gas_elastic_keys_unique`, SPP plan §7 gate G10) that fails if one key names a
neighbour of two ISOs. Against SPP's three names:

| SPP neighbour | Key state | Consequence for SPP-51 |
|---|---|---|
| `MISO` | **collides** — PJM already registers a `MISO` seam | **BLOCKED.** Adding `"MISO"` fails the import. SPP↔MISO has no armable forward elasticity at HEAD |
| `AECI` | free | armable |
| `ERCOT` | free | armable in principle — **but must not be** (degenerate fit, above) |
| — | `"SPP"` is **MISO's** SPP seam | must not be reused or re-fitted (rule 25) |

So the only seam whose fit is *both* sound and keyable is **AECI**. Resolving the MISO collision
needs an `(iso, neighbour)` key or a `NeighborInterface` field — a `neighbor_price.py` change,
which is neither this lane's nor, on its face, SPP-51's single-lever scope. **Routed as §6 R3.**
None of this touches the first keeper: `hr_by_year` is a per-`NeighborInterface` field with no
global keying, so §3's table arms cleanly in 2023–2025 regardless.

## §A — the listing these files reproduce from

```python
"""SPP-33 — SPP seam evidence for SPP-51 to arm. DERIVE ONLY; arms nothing."""
from __future__ import annotations

import numpy as np
import pandas as pd

from market_sim.config import paths
from market_sim.config.constants import HENRY_HUB_TRAJECTORIES
from market_sim.config.interchange_config import INTERFACE_NEIGHBORS
from market_sim.data.neighbor_price import neighbor_gas_price, neighbor_load_shape

HOURS = 8760
YEARS = [2023, 2024, 2025]
OUT = paths.RAW_DIR / "reference"

# The anchors SPP-20 REGISTERED, block by block (spec.py "SPP" comments).
ANCHOR = {
    "MISO": dict(file="actual_lmp_hourly_zonal_MISO.parquet",
                 zones=("MISO-West", "MISO-South"),
                 kind="zonal; per-zone mean then equal weight over the two bordering zones"),
    "AECI": dict(file="actual_lmp_hourly_SPP.parquet", zones=None,
                 kind="PROXY - SPP's own system hub (AECI publishes no LMP)"),
    "ERCOT": dict(file="actual_lmp_hourly_ERCOT.parquet", zones=None,
                  kind="system"),
}
# neighbour -> the EIA-930 SWPP DIBA that IS this seam.
SEAM_DIBA = {"MISO": "MISO", "AECI": "AECI", "ERCOT": "ERCO"}


def anchor_mean(name: str, year: int, run: str) -> tuple[float | None, int]:
    """Annual-mean anchor price ($/MWh) on the construction SPP-20 registered.

    A zonal anchor averages PER ZONE and then over zones: MISO-South carries
    four hubs to MISO-West's one, so a row-pooled mean would weight South 4:1
    and is NOT what the registration's stated 27.90 / 26.27 / 37.82 means are.
    """
    spec = ANCHOR[name]
    df = pd.read_parquet(paths.CALIBRATION_DIR / spec["file"])
    rows = df[df["year"] == year]
    if spec["zones"] is not None:
        rows = rows[rows["zone"].isin(spec["zones"])]
        if rows.empty:
            return None, 0
        return float(rows.groupby("zone")[run].mean().mean()), int(len(rows))
    if rows.empty:
        return None, 0
    return float(np.nanmean(rows[run].to_numpy(dtype=float))), int(len(rows))


def hr_table(run: str) -> pd.DataFrame:
    recs = []
    for nb in INTERFACE_NEIGHBORS["SPP"]:
        for y in YEARS:
            m, n = anchor_mean(nb.name, y, run)
            shaped = neighbor_load_shape(nb, y, HOURS)
            if m is None or shaped is None:
                continue
            k = float(np.nanmean(shaped[0] ** 1.0))
            gas = neighbor_gas_price(nb, y)
            hr = m / (gas * k)
            flat_price = gas * nb.marginal_heat_rate * k
            recs.append(dict(
                neighbor=nb.name, year=y, run=run,
                anchor_file=ANCHOR[nb.name]["file"],
                anchor_kind=ANCHOR[nb.name]["kind"],
                anchor_rows=n, shape_ba=shaped[1],
                mean_lmp_usd_mwh=round(m, 4),
                henry_hub_usd_mmbtu=round(HENRY_HUB_TRAJECTORIES["mid"][y], 4),
                gas_basis_usd_mmbtu=round(nb.gas_basis, 4),
                delivered_gas_usd_mmbtu=round(gas, 4),
                shape_convexity_k=round(k, 6),
                hr_by_year_mmbtu_mwh=round(hr, 2),
                registered_marginal_heat_rate=nb.marginal_heat_rate,
                flat_hr_constructed_mean_usd_mwh=round(flat_price, 2),
                flat_hr_error_pct=round(100.0 * (flat_price - m) / m, 2),
            ))
    return pd.DataFrame.from_records(recs)


def elasticity_table(hr: pd.DataFrame) -> pd.DataFrame:
    recs = []
    for nb in INTERFACE_NEIGHBORS["SPP"]:
        sub = hr[hr.neighbor == nb.name].sort_values("year")
        if len(sub) < 2:
            continue
        gas = sub.delivered_gas_usd_mmbtu.to_numpy(float)
        price = (sub.mean_lmp_usd_mwh / sub.shape_convexity_k).to_numpy(float)
        hr_phys, hr_adder = np.polyfit(gas, price, 1)
        hr_phys, hr_adder = round(float(hr_phys), 2), round(float(hr_adder), 2)
        pred = hr_phys * gas + hr_adder
        ss_res = float(((price - pred) ** 2).sum())
        ss_tot = float(((price - price.mean()) ** 2).sum())
        r2 = 1.0 - ss_res / ss_tot if ss_tot > 0 else float("nan")
        for _, r in sub.iterrows():
            meas = float(r.hr_by_year_mmbtu_mwh)
            elast = hr_phys + hr_adder / float(r.delivered_gas_usd_mmbtu)
            recs.append(dict(
                neighbor=nb.name, year=int(r.year), n_points=int(len(sub)),
                hr_phys_mmbtu_mwh=hr_phys, hr_adder_usd_mwh=hr_adder,
                fit_r2=round(r2, 4), hr_phys_sign_ok=bool(hr_phys > 0),
                delivered_gas_usd_mmbtu=float(r.delivered_gas_usd_mmbtu),
                measured_hr=meas, flat_hr=nb.marginal_heat_rate,
                elastic_hr=round(float(elast), 2),
                abs_err_flat=round(abs(nb.marginal_heat_rate - meas), 2),
                abs_err_elastic=round(abs(float(elast) - meas), 2),
            ))
    return pd.DataFrame.from_records(recs)


# SIGN CONVENTION, stated once and carried on every emitted row:
#   EIA-930 BA-to-BA net interchange, mw > 0 = SWPP EXPORTS to the DIBA;
#   mw < 0 = SWPP IMPORTS from it. Confirmed against SPP's OWN meter below.
# Three impossible prints in the 2023-2025 window (data/raw/eia-930-interchange/
# README.md) are EXCLUDED and COUNTED, never silently dropped. None of the three
# is on a registered seam, so MISO / AECI / ERCO are untouched by the exclusion.
IMPOSSIBLE = {
    ("SPC", pd.Timestamp("2024-07-19 00:00")),
    ("SPC", pd.Timestamp("2025-11-19 15:00")),
    ("WACM", pd.Timestamp("2025-06-21 05:00")),
}
PCTS = [0, 1, 5, 10, 25, 50, 75, 90, 95, 99, 100]


def _swpp_interchange() -> pd.DataFrame:
    df = pd.read_parquet(
        paths.RAW_DIR / "eia-930-interchange" / "SWPP interchange hourly.parquet"
    )
    df["diba"] = df["diba"].astype(str)
    df["year"] = df["local_time"].dt.year
    return df


def diba_table(df: pd.DataFrame) -> pd.DataFrame:
    d = df[df.year.isin(YEARS)].copy()
    d["excluded"] = [k in IMPOSSIBLE for k in zip(d["diba"], d["local_time"])]
    seam_of = {v: k for k, v in SEAM_DIBA.items()}
    recs = []
    for (diba, year), g in d.groupby(["diba", "year"], observed=True):
        n_excl = int(g.excluded.sum())
        g = g[~g.excluded]
        obs = g["mw"].to_numpy(float)
        obs = obs[~np.isnan(obs)]
        if obs.size == 0:
            continue
        rec = dict(
            diba=diba, year=int(year),
            registered_seam=seam_of.get(diba, ""),
            sign_convention="mw>0 = SWPP exports to DIBA",
            hours_in_file=int(len(g)), hours_with_value=int(obs.size),
            hours_nan=int(len(g) - obs.size), hours_excluded_impossible=n_excl,
            export_hours=int((obs > 0).sum()), import_hours=int((obs < 0).sum()),
            zero_hours=int((obs == 0).sum()),
            export_hour_share=round(float((obs > 0).mean()), 4),
            mean_mw=round(float(obs.mean()), 2),
            net_twh=round(float(obs.sum()) / 1e6, 4),
            export_twh=round(float(obs[obs > 0].sum()) / 1e6, 4),
            import_twh=round(float(obs[obs < 0].sum()) / 1e6, 4),
        )
        for p in PCTS:
            rec[f"p{p:02d}_mw"] = round(float(np.percentile(obs, p)), 1)
        recs.append(rec)
    return pd.DataFrame.from_records(recs).sort_values(["diba", "year"])


def limit_table(df: pd.DataFrame) -> pd.DataFrame:
    recs = []
    for nb in INTERFACE_NEIGHBORS["SPP"]:
        d = SEAM_DIBA[nb.name]
        for y in YEARS:
            s = df[(df.diba == d) & (df.year == y)]["mw"].to_numpy(float)
            s = s[~np.isnan(s)]
            if s.size == 0:
                continue
            over = int((np.abs(s) > nb.interface_limit_mw).sum())
            recs.append(dict(
                neighbor=nb.name, diba=d, year=y,
                registered_interface_limit_mw=nb.interface_limit_mw,
                hours_with_value=int(s.size),
                hours_abs_flow_over_limit=over,
                share_over_limit=round(over / s.size, 5),
                max_abs_mw=round(float(np.abs(s).max()), 1),
                max_export_mw=round(float(s.max()), 1),
                max_import_mw=round(float(s.min()), 1),
                headroom_ratio_limit_over_max=round(
                    nb.interface_limit_mw / float(np.abs(s).max()), 3),
            ))
    return pd.DataFrame.from_records(recs)


def tieflow_table(df: pd.DataFrame) -> pd.DataFrame:
    """SPP's own 1-minute tie flows vs EIA-930 over the overlap (SPP-14 file).

    Sanity check ONLY: it establishes that the EIA-930 sign convention and
    magnitude match SPP's own meter on each registered seam. No parameter is
    derived from it. TieFlows columns are per-entity, so the MISO seam is the
    sum of SPP's MISO-member tie columns and ERCOT the sum of its two DC ties.
    """
    tf = pd.read_csv(
        paths.RAW_DIR / "spp-planning" / "TieFlows_Sep2025.csv", parse_dates=["GMTTIME"]
    )
    local = tf["GMTTIME"].dt.tz_convert("America/Chicago").dt.tz_localize(None)
    tf["he"] = local.dt.ceil("h")  # EIA-930's hour-ENDING local stamp
    MISO_MEMBERS = ["AMRN", "MEC", "ALTW", "DPC", "GRE", "MDU", "NSP", "OTP", "EES", "CLEC"]
    tf["ERCOT_ties"] = tf["ERCOTE"] + tf["ERCOTN"]
    tf["MISO_members"] = tf[MISO_MEMBERS].sum(axis=1)
    cols = ["AECI", "ERCOT_ties", "MISO_members", "SPA", "SPC"]
    hourly = tf.groupby("he")[cols].mean().add_prefix("tf_")
    piv = (df[(df.local_time >= hourly.index.min()) & (df.local_time <= hourly.index.max())]
           .pivot_table(index="local_time", columns="diba", values="mw", observed=True)
           .add_prefix("e_"))
    j = hourly.join(piv, how="inner")
    pairs = [("MISO", "tf_MISO_members", "e_MISO", "+".join(MISO_MEMBERS)),
             ("AECI", "tf_AECI", "e_AECI", "AECI"),
             ("ERCOT", "tf_ERCOT_ties", "e_ERCO", "ERCOTE+ERCOTN"),
             ("", "tf_SPA", "e_SPA", "SPA"),
             ("", "tf_SPC", "e_SPC", "SPC")]
    recs = []
    for seam, a, b, src in pairs:
        k = j[[a, b]].dropna()
        if k.empty:
            continue
        recs.append(dict(
            registered_seam=seam, tieflow_columns=src, eia930_diba=b[2:],
            overlap_hours=int(len(k)),
            correlation=round(float(np.corrcoef(k[a], k[b])[0, 1]), 4),
            mean_tieflow_mw=round(float(k[a].mean()), 1),
            mean_eia930_mw=round(float(k[b].mean()), 1),
            mean_diff_mw=round(float((k[a] - k[b]).mean()), 1),
            signs_agree=bool(np.sign(k[a].mean()) == np.sign(k[b].mean())),
        ))
    return pd.DataFrame.from_records(recs)


def main() -> None:
    OUT.mkdir(parents=True, exist_ok=True)
    hr = pd.concat([hr_table("rt"), hr_table("da")], ignore_index=True)
    hr.to_csv(OUT / "spp_seam_hr_by_year.csv", index=False)
    elasticity_table(hr[hr.run == "rt"]).to_csv(
        OUT / "spp_seam_hr_elasticity.csv", index=False)
    df = _swpp_interchange()
    diba_table(df).to_csv(OUT / "spp_seam_diba_duration.csv", index=False)
    limit_table(df).to_csv(OUT / "spp_seam_limit_binding.csv", index=False)
    tieflow_table(df).to_csv(OUT / "spp_seam_tieflow_crosscheck.csv", index=False)


if __name__ == "__main__":
    main()
```

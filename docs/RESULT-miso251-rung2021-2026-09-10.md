## 6. One deviation from the launch script, and it changed nothing

```

scripts/legitimacy_diagnostics.py --bundle ... manually
```

The cause is an ordering dependency, not a defect in the bundle: the diagnostic's D-4 leg loads
`frontend/data/backcast/bench/MISO/2021.json.gz`, which **`dashboard_add_run.py` itself creates**.
So the file cannot exist until registration has run. The fix was to run the exact command the
warning prints, **after** registration — steps 4 → 5 → diagnostics → score. C8 and the D-1/D-2/D-4
rows in §4.3 come from that artifact. **No file under `src/` or `scripts/` was edited**, and
`calibration_verdict.py` was then run against the complete bundle.

Two other invocation notes, neither a code change: `PYTHONPATH=src:.` was needed where the launch
prompt said `PYTHONPATH=.` (`ModuleNotFoundError: market_sim` otherwise), and
`curate_capacity_deliverability.py` wrote 5 partitions (MISO 776 rows) — which is why

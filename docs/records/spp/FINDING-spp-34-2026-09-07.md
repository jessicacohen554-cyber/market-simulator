header, not the row — so every SPP row got `source: "NEEDS CITATION — no source comment found in
code"`. But SPP-20 wrote a cited comment block directly above (or trailing) **every** `"SPP"` key.

`<module>::<CONSTANT>["SPP"]`, `last_verified` 2026-09-07, and clears the `needs-citation` /
`auto-generated` flags. Two deliberate choices, so neither reads as a guess:

- **`source_date` = `2026-09-06` (the registration date) for all 33**, not a year scraped from the
  comment. Every SPP block names *target* years beside its publication years — 2050 load horizons,
  2040 RPS targets, the 2029 PRM step — and a first pass duly wrote `source_date: 2050` for the six
  `demand_growth_rates` rows. The primary document is named verbatim in `source` instead (SOM 2025
  §4 report p. 119, Planning Criteria v5.0A §4 p. 10, EIA-860 2025 ER, …).
- **`voluntary_baseline_iso_weight.SPP` keeps a `needs-intake` flag.** Its value is `None` and its
  comment says so — the EIA-861 gap it shares with every other ISO in that table. Registering it as
  "cited" without the flag would have been the dishonest option.

`docs/parameter-citations.md` is **rendered from the JSON by the generator** — not hand-edited

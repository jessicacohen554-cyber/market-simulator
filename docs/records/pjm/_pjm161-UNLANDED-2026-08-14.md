## 3. The two solved arms — registered locally, bundles NOT pushable

Both arms solved in-session (`--year 2023 2024 2025`, one invocation, years
sequential) and were registered locally with `scripts/dashboard_add_run.py`,
which printed their determinations. **Their dashboard files cannot cross the API
path**: each run payload `frontend/data/backcast/runs/<id>.js` is ~2.2 MB
(against a ~457 KB cap) and each bundle's `hourly/*.parquet` is binary.

Registry sidecars are therefore **deliberately not left on this branch**: a
sidecar without its payload is a hard failure of
`scripts/check_registry_payload_parity.py`, so landing them alone would break CI
for every later PR. The runs must be re-solved and re-registered by a session
with a working git write path:


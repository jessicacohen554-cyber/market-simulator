Forecast Run Explorer

Every registered run of the Forecast Finalization Program (FF), grouped by kind and tier. Each run shows its rubric verdict (FC-1..FC-8), the forecast invariants (I1..I14), the evolution ledger, and capacity / CO2 / price trajectories. Forecast runs live on a namespace separate from the backcast registry (plan §7.5) — the backcast CI gates never see a forecast id. Sibling pages: Program Status (the §2.1b gate board) and Forecast Bands.

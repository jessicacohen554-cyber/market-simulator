Data Completeness

A gathering checklist of the measured datasets for the Jan 2018 – Jun 2026 backcast window — distilled from docs/data-register-2026-07.md and re-verified against files on disk 2026-07-10 (full-coverage sources are omitted). The % complete is data-driven: each row carries a status (GATHERED PARTIAL MISSING BLOCKED) and the bar weights them (gathered = 1, partial = 0.5); BLOCKED items are not fetchable and are excluded from the denominator. Ticking a row marks it gathered locally (saved in this browser only) and updates the bar. Holdout-year intake (2022, 2019, ≤2021, H1 2026) is gated on per-ISO owner authorization & the calibration-complete marker (rule 22).

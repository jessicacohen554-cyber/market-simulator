Cross-ISO Mechanism Matrix

Every model mechanism × every ISO: is it armed in the ISO's current backcast keeper (or forecast default), has it been tested there, and what was the verdict. This page renders the canonical sharded ledger: mechanism-level rows in data/mechanism-matrix.js plus one per-ISO shard data/mechanism-matrix/<ISO>.js holding that ISO's verdicts, evidence and keeper/gates stamps — a session that tests a mechanism in an ISO updates ONLY its own ISO's shard, in the same session (CLAUDE.md rule 28 [R-MECH-MATRIX]). Methodology, per-ISO lever queues and update protocol: docs/mechanism-testing-matrix.md. Click a row for its note and evidence citations.

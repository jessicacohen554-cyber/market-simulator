What this page shows

Three distinct claims, never conflated (plan §0.5): a deterministic scenario range (the dashed envelope across 13 named AEO/IPM-style cases — no likelihood attaches to it or to any single case), a parametric probability band (the P10–P90 fan from the correlated multivariate sampler), and a published band (parametric ⊕ the structural-error prior, when available). The chart never displays a band its metadata cannot defend — see the banners above for this payload's specific caveats.

Source: docs/handoffs/probability-bounds-plan-2026-07.md §4. Exporter: scripts/export_forecast_bands.py.

The individual forecast runs behind these bands live in the Forecast Run Explorer; per-ISO tier and gate state is on the Forecast Program Status board.

This is consistent with `RESULT-caiso-fuelvintage-2026-09-09.md` §6c, which measured the fuelvintage
changes as material only in 2023 (the plant-356 redistribution) and provably inert on the gas leg. So
in **2025** the new keeper and the old one are the same run for this purpose, and the ×0.92 cut
reproduces caiso-267's 2025 result to three decimals on every number measured.

Stated plainly and against interest: **for this year, the "new evidence" that licensed the re-test under
rule 28's DO-NOT-REDO discipline is absent.** It may well be present in 2023, which is where the
fuelvintage change actually bit and which is another shard's year — this shard can only speak for 2025.

# reference — raw

Loose crosswalks and per-ISO reference lookups that don't belong to a single
named clean datatype. Each file's provenance:

| File | What it is | Producer | Source |
|---|---|---|---|
| `*.ACTUALSYSLOADWZNP6345_csv.zip` (19 files) | ERCOT NP6-345-CD "Actual System Load by Weather Zone" monthly-sample daily archives (2023) | manual ERCOT MIS download | ERCOT MIS |
| `custom-bin-assignments.csv` | ERCOT's hand-curated dispatch-bin assignment table (the only ISO with a hand-curated bin file; other ISOs synthesize bins at runtime — see `_processed-legacy/bin_assignments_*.csv`) | hand-authored | — |
| `iso_zone_weather_stations.csv` | NOAA station → model-zone weight crosswalk (`iso, zone, station_id, weight, station_name`) | hand-authored | NOAA station metadata |
| `lcr_area_membership_CAISO.csv` | CAISO Local Capacity Requirement area assignment per thermal plant | `scripts/derive_lcr_membership.py` | EIA-860 + CAISO NQC-list overrides + geographic rules |
| `master-plant-registry.csv` | plant/ISO/zone crosswalk registry used across the fleet, outage, and emissions pipelines | hand-maintained — no producing script found | — |
| `nerc-gads-eford-2019-2023/` | already documented — see its own `README.md` | `scripts/curate_reference.py` (consumer) | NERC GADS Generating Unit Statistical Brochure 3, 2019–2023 |
| `nyiso_campd_marginal_hr_summary.csv` | NYISO CAMPD-derived marginal heat-rate summary | consumed by `scripts/run_calibration.py` — producing script not confirmed in this checkout | CAMPD |
| `nysdec-227-3-peaker-compliance.csv` | NY State DEC "Peaker Rule" (6 NYCRR Part 227-3) compliance/retirement table | hand-curated from the DEC rule text | NY DEC |
| `reliability_floor_coeffs_<ISO>.csv` (6 files) | per-ISO reliability-floor regression coefficients | `scripts/derive_reliability_coeffs.py` | model-side derivation |
| `tx-jan-aug23-unit-outages.csv` | ERCOT-specific unit outage list, Jan–Aug 2023 | hand-curated — no producing script found | ERCOT outage reporting |

**Regeneration:** files with a listed producing script regenerate by
re-running it; files marked "hand-authored"/"hand-curated — no producing
script found" are **hand-assembled — refetch procedure unknown** and should
not be regenerated by guessing at a source.

**Consumers:** `scripts/curate_reference.py`, `scripts/curate_fleet.py`,
`scripts/curate_outages.py`, `scripts/derive_plant_emissions.py`,
`scripts/derive_parasitic_load.py`, `scripts/derive_load_shares.py`,
`scripts/run_calibration.py`, `scripts/run_calibration_full.py`,
`src/market_sim/data/{fleet,hydro,cod_ramp,outages}.py`,
`src/market_sim/{model/transmission.py, config/scenarios.py, config/iso_configs.py}`.

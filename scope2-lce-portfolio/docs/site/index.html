Scope 2 Hourly LCE Portfolio Optimization Tool

A self-contained decision tool that picks the least-cost mix of clean generation + storage to match an hourly load, and reports how far that match can go for a given cost premium above wholesale.

Overview Mechanics Inputs Decisions

What it does

Given a facility or company's hourly load and the prevailing wholesale price (BAU LMP), the tool answers: how hourly-matched with carbon-free energy can we get for a $1 / $2 / $5 / $7 / $10 / $20 premium — and with what mix of wind, solar, nuclear, geothermal, hydro, batteries, LDES and hydrogen?

It sweeps a premium ladder (or a matching-target ladder, in reverse mode) and reports the matching %, cost, resource build, and residual carbon reachable at each point. Because grid purchases and surplus sales both settle at the hourly wholesale price, the optimizer naturally spends its budget covering the most expensive hours first — that behavior falls out of the linear program, not a heuristic layered on top.

Mode A — premium cap

Default. Fix a premium budget, maximize hourly matching: “how matched can we get for $X?”

Mode B — matching target

Fix a matching goal, minimize the premium: “what does 90% (or strict 24/7) cost?”

Standalone

No import market_sim anywhere. Consumes a BAU LMP file as input; never modifies or imports the market simulator's LP core.

§Quickstart

From scope2-lce-portfolio/, using the repo's virtualenv:

../.venv/bin/python examples/run_sample_sweep.py          # synthetic end-to-end demo
../.venv/bin/python -m pytest tests/ -q                    # test suite

# on your own data (run_portfolio.py puts src/ on the path -- no install needed):
../.venv/bin/python run_portfolio.py \
    --load data/inputs/my_load.csv --lmp data/inputs/bau_lmp.csv \
    --iso ERCOT --deltas 1 2 5 7 10 20 --out-dir data/outputs

Or double-click launcher/run_lce.sh (macOS/Linux) / run_lce.bat (Windows) for the no-command-line path — see the launcher tour below.

Pulling the folder out of this repo entirely? Run scripts/verify_standalone.sh — see Mechanics § Running standalone.

§Launcher tour

The desktop launcher (ADR 0016) needs no command line: a double-clicked script starts a local server and opens a form in your browser. Configure a run, queue it, submit — runs execute one LP solve at a time and open their report when done.

  • Exposed parameters: ISO, mode, premium deltas / matching targets, LCOE sensitivity, load & LMP file paths, run ID, open-report-when-done — everything else stays config-file-only.
  • Past runs & run log (HP-03): every results/<run_id>/ with valid metadata is browsable, and the last 20 finished runs are recorded in launcher/run_log.jsonl.
  • Input dropdowns only ever list four whitelisted directories (bundled LMP, templates, inputs, the reference load) — never arbitrary filesystem browsing.

Full flow, run-log detail, and the security posture: see Mechanics § The launcher.

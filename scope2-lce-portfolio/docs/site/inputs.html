§Data flow

§Load intake

CSV or Parquet, long form. Facility-level and multi-ISO rows are allowed — the tool auto-aggregates.

ColumnTypeRequiredNotes
hourint 0–8759yeshour index within the year
isostryesISO the row belongs to
load_mwhfloatyesconsumption in that hour
facilitystrnosummed away by aggregation
Auto-aggregation: intake sums all facilities within each (iso, hour) automatically (ADR 0010) — provide as many facility rows per hour as you like; the facility column may be omitted entirely if your data is already ISO-level.

§LMP intake — two formats

Pick one. Both are schema-detected from the file's columns; both apply the same validation idioms (duplicate row, missing ISO, non-finite/negative price are all hard errors).

Hourly (preferred, ADR 0011)

ColumnTypeNotes
hourint 0–8759every hour present per ISO
isostrmust cover every ISO in your load file
lmpfloat ($/MWh)BAU wholesale price

Hourly LMPs preserve the price shape the optimizer exploits — premiums and matching frontiers are shape-aware.

Annual-average (HP-01)

ColumnTypeNotes
isostrone row per ISO
annual_avg_lmpfloat ($/MWh)annual average wholesale price
Flat-price caveat: no hour column — intake detects this schema and expands each ISO's value to a flat 8760 vector. This makes the run an annual-average-price comparison, not a shape-aware one: hourly price shape/covariance value is deliberately excluded, since a flat price gives the optimizer no expensive-hour signal to target. The run's lmp_kind metadata and the report's provenance section both read annual_average_flat so this is never confused with a real hourly run.

Fillable skeletons

data/templates/ ships three small, human-readable example CSVs (one per schema above); scripts/make_input_templates.py writes full 8760-row fillable skeletons into the gitignored data/templates/skeletons/ so you only overwrite values.

§Bundled data inventory

Committed for standalone pull-out (HP-02 / HP-02b) — every ISO carries a real, provenance-sidecarred 2024 backcast BAU LMP export and fossil-avg CO₂ rate. Each is a 2024-only bridge re-solve of that ISO's then-current calibration keeper — a backcast-validation carve-out (ADR 0015), never a registered dashboard keeper.
